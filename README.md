# Theme-changing React Portfolio

A responsive React + Vite portfolio starter with:
- Dark / light mode toggle (saved in localStorage)
- Four accent themes: Violet, Cyan, Orange, Green (saved in localStorage)
- Responsive navigation and mobile layout
- About, Skills, Projects and Contact sections

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Personalize before publishing
- In `src/App.jsx`, replace `Kishore`, role, bio and skills with your exact details.
- Replace `your.email@example.com` with your real email in the mail links.
- Replace the GitHub and LinkedIn profile URLs with your own profile URLs.
- Update the project cards with accurate descriptions, technologies, GitHub links and demo links. The RoadEar card is only a starter placeholder.
- Add your resume file and a download link if you want a resume button.

Do not publish placeholder contact details or claim skills you do not have.
